# Alpha Sniper Vault

This directory serves as the sanctuary for Alpha Sniper's Intellectual Property (IP).

## Contents

* `mql5/` - Source code for Expert Advisors, indicators, and orchestrators.
* `src/` - Python source code for data pipelines, meta-labeling, and Global Optimizer.
* `api/` - FastAPI and production server code.
* `models/` - Serialized `.onnx` and `.pkl` models for Entry and Exit execution.
* `data/` - Raw and processed datasets, feature matrices (CSVs).
* `reports/` - Backtesting, Monte Carlo, and stress test raw reports.

## Confidentiality
This repository contains proprietary quantitative trading algorithms and models. Strict confidentiality must be maintained.
